# Kami fork of hello.js

This branch tracks [MrSwitch/hello.js](https://github.com/MrSwitch/hello.js) (`upstream/main`) and carries the changes Kami needs on top.
`notablemain` and `kamitools` install this repository by commit SHA and load `dist/hello.all.js`, so `dist/` is committed here even though upstream no longer commits it.

## Updating from upstream

```sh
git fetch upstream
git merge upstream/main
npm ci
PATH=$PWD/node_modules/.bin:$PATH bash build.sh   # regenerates dist/
PUPPETEER_EXECUTABLE_PATH=<chrome> npm test
```

Edit `src/` only. `dist/` is generated by `build.sh`; earlier Kami commits edited `dist/` by hand, which is how fixes ended up missing from `src/`.

## Changes carried on top of upstream

| Area | Change | Why |
| --- | --- | --- |
| `hello.utils.responseHandler` | Result is sent with `parent.postMessage` (origin checked, callback name must start with `_hellojs_`) instead of calling `parent[callback]` directly. `hello.login` registers the `message` listener. | Popups lose a usable `window.parent` / `window.opener` on some browsers. |
| `hello.utils.responseHandler` | `BroadcastChannel` fallback when `window.parent === window` (iOS 18 Safari on iPad). | Same. |
| `hello.utils.responseHandler` | `chrome.runtime.sendMessage` to `chrome_ext_id` when running in the Kami extension. `src/hello.chromeapp.js` is replaced by the listener for those messages. | Kami extension sign-in. |
| `hello.utils.responseHandler` | Window close is delayed 300ms. No automatic redirect to `page_uri`. | Late messages; the app handles navigation itself. |
| `src/hello.js` bottom | `responseHandler` is **not** run on load. Redirect pages call `hello.utils.responseHandler(window, window.opener \|\| window.parent)`. | Running it automatically conflicts with other OAuth handlers (for example Clever). |
| `hello.utils.responseHandler` | `granted_scope` holds the scope Google returned; `scope` stays the requested scope. | Granted-scope checks in the apps. |
| `hello.login` | `popupOpenedCallback(popup)` option. | Apps track the popup. |
| `hello.login` | `display: 'none'` rejects with `timeout` after `options.timeout` and removes the iframe. | Immediate auth must not hang. |
| `hello.utils.store` | `getStorageStatus()` and `hello.utils.getLocalStorageStatus()`. Breadcrumb to `window.bugsnagClient` on every write. | Diagnosing blocked storage. |
| `hello.api` | `access_token` is not added to the query string. | Google and GitHub deprecated query-string tokens. |
| `hello.utils.error` / xhr `onerror` | Optional `other_data` with the event and request. | Debugging network errors. |
| `modules/google.js` | `me/files` serves single files and lists; `supportsTeamDrives=true` on Drive calls; `PATCH` sends a JSON body; `Authorization: Bearer` header from `p.authResponse`; `basic` scope is `profile` (no `openid`). | Drive usage in the apps. |
| `build.sh` | `hello.all.js` does not include `hello.phonegap.js`. | Matches the previous Kami bundle. |

## Dropped because upstream has them

- `oauth_redirect` URL validation and the `_hellojs_` callback name check (XSS fixes).
- Popup top/left positioning from options.
- Closing a hidden iframe from `closeWindow`.
- `hello.polyfill.js`. Upstream removed it; browsers without ES5 are not supported.
